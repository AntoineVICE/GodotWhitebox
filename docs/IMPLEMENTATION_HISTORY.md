# 当前更新：口头表态与实际行动分离（2026-09-24）

## 当前行为

- 三种初次回答中加入明确拒绝；分别记录 promised_help / refused_help。口头回答不完成任务、不结束游戏、不阻止后续行动。
- 好感 + 字条仍共同开放私密话题；低属性仍可选择，选择后才做检定。成功/失败只决定问出的信息，不决定是否能取药或交付。
- 晚祷钟仅要求当前是晚祷前，不依赖同意、线索、好感或检定。NPC 仍按配置从回廊移动到草药房。
- 草药柜现在使用普通物体对话。晚祷前可以查看，晚祷时可选择取药或离开。
- 取药单独提交 poppy_taken / poppy_held，并记录 cabinet_poppy 一次性键。它不会交付、完成任务或弹出结局；关闭物体对话后可以继续行走、换房间和存读档。
- 携带药包与罗德里戈交谈时出现明确的 hand_over 选项，清除携带状态、记录实际交付，并按 JSON 固定增加罗德里戈好感 +5。所有数值仍是测试值；修士好感不变。
- 交付后显示回应，初次拒绝的角色会听到对应的惊讶对白。此时仍可暂时离开；重开对话可以接着告别，不能重复交付领奖。
- 结果由 NPC 对话中的最后告别触发。也可以当面最终拒绝；确认前能返回继续探索。任务在最后告别后才完成。
- HUD 调查笔记显示药包尚未取走、随身携带或已交付。物品进度使用任务 flag，不增加背包系统。
- 语义分离：携带、交付、口头答应、口头拒绝互不代替；带着药最终不交付时，结局文案不会虚构药已交出去。
